The gap

A search for agent extraction of conservation plans for credit origination returned nothing in agriculture. The nearest published analogue is in medicine.

CAST holds the rates. The reference guide holds the conditions. The regulation holds the rules. Nothing reads the document a farm actually arrives as — and refuses when it cannot.

How it works

Eight agents. None of them may state a number.

  • Plan reader — extract and validate every practice name
  • Eligibility — what the farm could physically host
  • Alignment — which reference sheet governs, width, duration
  • Opportunity — what the project leaves on the table
  • Quantification — the only numeric role
  • Verification — inspection schedule
  • Drafter — holds zero tools by design
  • Review desk — decides last, cannot pass a blocker

Every figure returns from a tool over 24,704 county rate rows. Fabrication is structurally impossible, not discouraged.

Creditability decided per practice, from the document. Nutrient Management held — already reported to Virginia DEQ. An existing CREP buffer held — not additional. Fence unresolved — a real cost, not a creditable practice.

Safety

The producer never reaches the model

Shown before the run starts and again in the result — a count the user can check, not a policy they have to believe.

Order of operations

Injection scan → jurisdiction → location: all local, on the original. Then redact. Then the agents, which see only the redacted text. Location detection needs the address — which is why it runs first, and locally.

Removed

Names, address, phone, email, farm and tract numbers, contract numbers, postcode, coordinates.

Kept

Nine practice lines, every quantity, the county, the EQIP / CREP / DEQ signals.

Output identical before and after: same seven creditable practices, same 3,087.8 lb N, same $27,130. Removing the person costs the screening nothing.

Prompt injection

Three injected instructions quoted and not obeyed. Clean plans: zero findings.

I worry about farmers' trust of the numbers, and their willingness to enter data like a conservation plan into AI. Also, this wouldn't work for our Amish farmers — roughly 10% of farmers — since they don't use technology. Director, Revolving Water Fund

Honest limits

35% of lost projects are a data-trust problem this tool does not solve — and may worsen. ~10% of producers are excluded outright, so the 60% conversation saving applies to about 90% of the base.
